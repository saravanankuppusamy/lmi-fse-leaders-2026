# Evergreen Quote — Composition & Hooks (Starter)

The working Week 3 React app — ready to be refactored with the patterns your
engineers use to keep larger apps maintainable: a **custom hook** and the
**Context API** (backed by `useReducer`).

## Run it

```bash
npm install
npm run dev
```

You will:

- Move the form logic into a custom hook: `src/hooks/useQuoteEstimate.ts`.
- Share the saved-quotes list through context: `src/context/QuotesContext.tsx`.
- Add a "Save this quote" button that updates the shared list — no prop drilling.

Follow the lab guide and look for the `TODO` comments.
