# Evergreen Quote — AI-Assisted Feature Work (Starter)

Practice building Evergreen features **with GitHub Copilot**, and reviewing
what it produces. You will use inline completions plus all four chat modes:
**Ask**, **Edit**, **Plan**, and **Agent**. The discipline is the same in every
mode: **accept, inspect, edit, test.**

## Run it

No install needed — this uses Node's built-in test runner.

```bash
node --test
```

Files:

- `evergreen-features.js`: the coding exercises. Generate from a spec, fix an
  AI-introduced bug, spot a hallucinated API, explain and refactor unfamiliar
  code, and plan/delegate a new feature.
- `test.mjs`: the tests that verify your work.
- `prompts.md`: a prompt-engineering exercise.

Follow the lab guide and look for the `TODO` comments. Re-run `node --test` until
everything passes.
