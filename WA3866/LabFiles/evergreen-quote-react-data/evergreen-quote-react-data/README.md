# Evergreen Quote — Beyond the Basics (Starter)

The Evergreen React app, ready to learn the most important "beyond the basics"
skill: loading data from a server with **useEffect**, handling **loading**,
**error**, and **success** states the way a real app must.

## Run it

```bash
npm install
npm run dev
```

The recent-quotes data lives in `public/quotes.json` (Vite serves it at
`/quotes.json`). Your job is to fetch it in `src/components/RecentQuotes.tsx`
using `useEffect`. Follow the lab guide and the `TODO` comments.
