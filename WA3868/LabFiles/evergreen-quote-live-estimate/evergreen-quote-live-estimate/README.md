# Evergreen Quote — Live Estimate (Starter)

This is the Phase 1 Evergreen Insurance Quote Page, now ready for JavaScript.
The HTML and CSS are done. Your job in this lab is to make the page **interactive**
by filling in the JavaScript in `app.js`.

By the end you will have:

- A `calculatePremium()` function that returns a monthly premium.
- A live estimate that updates as the form changes.
- Input validation using `try` / `catch` and a thrown `Error`.
- A list of recent quotes loaded asynchronously with `async` / `await` and `fetch`.

## Run it

Open this folder in VS Code and start the **Live Server** extension
(right-click `index.html` → **Open with Live Server**). The page must be served
over `http://` — opening the file directly will block the `fetch()` step.

Follow the lab guide step by step. Look for the `TODO` comments in `app.js`.
