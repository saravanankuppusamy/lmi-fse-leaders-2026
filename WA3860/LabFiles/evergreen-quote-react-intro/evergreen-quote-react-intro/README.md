# Evergreen Quote — Intro to React (Starter)

The Evergreen quote page, rebuilt as a **React + TypeScript** app (Vite).
The layout and helper code are provided. Your job is to fill in three
components so the page becomes interactive again — this time the React way.

## Run it

```bash
npm install
npm run dev      # open the URL Vite prints (usually http://localhost:5173)
```

Edit the files in `src/components/`:

- `QuoteForm.tsx` — holds form **state** with `useState` and recalculates the premium.
- `PremiumDisplay.tsx` — receives the premium through **props** and displays it.
- `RecentQuotes.tsx` — renders a **list** of quotes with `.map()`.

Follow the lab guide and look for the `TODO` comments.
