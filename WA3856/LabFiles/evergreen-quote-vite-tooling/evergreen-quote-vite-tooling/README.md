# Evergreen Quote — Vite & Build Tooling (Part 2 Lab)

A minimal **Vite + React + TypeScript** project, branded for Evergreen Insurance.
You will use it to explore the modern front-end build toolchain — the same tooling
your engineers use on every React project.

## Run it

```bash
npm install     # download React, Vite, and TypeScript into node_modules
npm run dev     # start the dev server (prints a localhost URL)
```

Then follow the lab instructions to:

1. Watch **Hot Module Replacement** update the page instantly as you edit.
2. Map the **npm scripts** (`dev`, `build`, `preview`) to what they do.
3. Run **`npm run build`** and inspect the optimized `dist/` output.
4. Add a **`.env`** file and read a `VITE_` environment variable.
5. Add a **path alias** (`@` → `src/`) in `vite.config.ts` and `tsconfig.json`.

You are not expected to write React. You are here to *see* the workflow.
